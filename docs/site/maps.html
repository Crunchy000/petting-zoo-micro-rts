Games stop at 2,000 ticks, so on the large maps most end in a draw before either side wins. Eight games per map is a small sample, so treat a few points either way as noise. The multi-map agent played only two games on each 24×24 and 32×32 map, and four games, capped at 1,200 ticks, on NoWhereToRun9x8 and letMeOut, where games rarely finish. To reproduce a row: python training/play.py training/agents/agent_16x16_maps.pt --map <map> --opponent mixed --games 8.
