MicroRTS as a PettingZoo environment

A two-player real-time strategy game for multi-agent RL. The engine is pure Python, matches the original Java engine tick for tick, and comes with action masks and a browser viewer with sound.

Get started Watch a trained agent Source on GitHub
A trained agent (player 0) beats the bundled mixed-army bot on basesWorkers16x16, using every unit and structure type. Space: play/pause · ←/→: step · m: sound · more: vs Ranged · vs Heavy · bot vs bot · bots on letMeOut
PettingZoo-nativeA Parallel env, plus the AEC version. Passes parallel_api_test, api_test, both seed tests and render_test.
No JVMThe MicroRTS rules are ported to NumPy, so pip install is all you need. CI compares it against the Java engine on every push.
Action masksEvery observation includes a mask, and action_space.sample(mask) picks only legal moves.
Viewer with soundA canvas renderer that shows games live while they run, or saves them as one-file HTML replays.

Install

git clone https://github.com/Crunchy000/petting-zoo-micro-rts
cd petting-zoo-micro-rts
pip install -e .            # numpy, gymnasium, pettingzoo
pip install -e ".[test]"    # + pytest

Usage

Parallel API (both players act every tick)

from microrts_pz import microrts_v0

env = microrts_v0.parallel_env(map_path="maps/16x16/basesWorkers16x16.xml", max_steps=2000)
observations, infos = env.reset(seed=42)

while env.agents:
    actions = {
        agent: env.action_space(agent).sample(observations[agent]["action_mask"])
        for agent in env.agents
    }
    observations, rewards, terminations, truncations, infos = env.step(actions)
env.close()

AEC API

env = microrts_v0.env(map_path="maps/8x8/basesWorkers8x8A.xml")
env.reset(seed=0)
for agent in env.agent_iter():
    obs, reward, termination, truncation, info = env.last()
    action = None if termination or truncation else env.action_space(agent).sample(obs["action_mask"])
    env.step(action)

Play against a scripted bot

from microrts_pz.bots import WorkerRushBot

bot = WorkerRushBot(harvesters=2, army="Light")
actions["player_1"] = bot.act(env.unwrapped.game, player=1).reshape(-1)

Environment

Agentsplayer_0, player_1 (simultaneous moves)
Action spaceflat MultiDiscrete of shape (H·W·7,), one 7-part action per map cell
ObservationDict(observation=Box(0,1,(H,W,29),int8), action_mask=Box(0,1,(H·W·78,),int8))
Stateenv.state(): fully observed planes, (H,W,29)
Terminationone side has no units left (infos[agent]["winner"])
Truncationmax_steps ticks (default 2000)

Per-cell action

The action for a cell is read only when the cell holds one of your idle units. Illegal actions turn into a wait of the same length, as in MicroRTS, so use the mask.

ComponentValues
action type0 wait, 1 move, 2 harvest, 3 return, 4 produce, 5 attack
move / harvest / return / produce direction0 up, 1 right, 2 down, 3 left
produce unit type0 Resource, 1 Base, 2 Barracks, 3 Worker, 4 Light, 5 Heavy, 6 Ranged
attack target0–48: a cell in the 7×7 square around the unit, (dy+3)*7 + (dx+3)

Rewards

infos[agent]["raw_rewards"] holds six components: win/loss, resources gathered, workers produced, buildings produced, attacks on enemies and combat units produced. The scalar reward is reward_weight @ raw_rewards, with a default of (10, 1, 1, 0.2, 1, 4). Pass reward_weight=(1, 0, 0, 0, 0, 0) for pure win/loss.

Viewer

Replays. Record an episode and save it as one HTML file with no external dependencies. The demo above was made this way.

env = microrts_v0.parallel_env(record_replay=True)
env.reset(seed=0)
...  # play
env.save_replay("game.html")

Live. render_mode="human" starts a local server on 127.0.0.1, opens your browser and streams every tick to it. You can pause and scrub back while the game keeps running.

python examples/replay_bots.py --out replay.html   # save a bot game
python examples/replay_bots.py --live              # watch it live

Sound effects are generated with the Web Audio API and panned by map position. Browsers only play audio after a click, so press 🔇 to turn it on.

Training agents

The sample games above are played by an agent trained with PPO and invalid-action masking (training/). It starts by imitating the bundled scripted bots, then plays against a pool of those bots and earlier copies of itself. The first model, training/agents/agent_16x16.pt, had about 16 million steps on one map, roughly three hours on a Colab L4 GPU. It wins about 60% of games against the mixed army, 75% against Ranged and all of them against Heavy, but loses most games to the Light rush.

A second model, training/agents/agent_16x16_maps.pt, continued from it for 200 million steps on 15 different 16×16 maps (about four hours), facing the Light rush twice as often. It now wins 38 to 100% of games on those maps against the mixed army, where the first model won 0 to 88%. The maps page has a replay and the win rate of both models on every bundled map, including the ones where they still lose.

pip install -e ".[train]"                # torch + numba
python training/train_selfplay.py --map maps/16x16/basesWorkers16x16.xml --bc-steps 2000000 --out runs/16x16
python training/play.py runs/16x16/latest.pt --opponent mixed --games 10 --record replays/

Training runs the games on microrts_pz.fast.BatchGame, a compiled batch engine that steps hundreds of games at once across all CPU cores and is checked against the reference engine tick by tick. A Colab notebook, training/train_colab.ipynb, runs the same steps in the browser.
